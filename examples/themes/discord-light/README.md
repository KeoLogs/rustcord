# Discord Light

Discord's light look. RustCord's only built-in look is the bordered
"blocky" one; this light version (flat panes, like Discord) is an example
theme you import.

Install: Settings → Themes → *Import folder…* and pick this folder (or
*Import theme…* and pick `theme.rctheme`). Settings → Themes → *Reset to
default* goes back to the built-in look.
