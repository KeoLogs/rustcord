# Discord Light

Discord's light look: flat panes, round avatars and badges, Noto Sans.

Since 0.8.0 this look is built in as **Discord Light** (Settings → Themes
→ *Apply*), so you don't need to import it. The file stays as an example
to copy and change.

Install anyway: Settings → Themes → *Import folder…* and pick this folder
(or *Import theme…* and pick `theme.rctheme`). Settings → Themes → *Reset
to default* goes back to RustCord Dark.
