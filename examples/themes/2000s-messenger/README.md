# 2000s Messenger (test theme)

An early-2000s instant messenger look: pale blue and white gradients, glossy
blue buttons, rounded boxes with soft drop shadows, outlined inputs, friendly
green / amber / red status colours and slightly smaller text.

For testing RustCord's theme system only — not shipped with RustCord. No
logos, names or images from any real messenger are used.

Install: Settings → Themes → *Import folder…* and pick this folder (or zip
it and use *Import theme…*).
