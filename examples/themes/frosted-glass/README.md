# Frosted Glass (test theme)

Converted from [Frosted Glass](https://github.com/DiscordStyles/FrostedGlass)
by Gibbu (MIT). Not shipped with RustCord: import it from Settings → Themes →
Import theme… and pick this folder.

`background.jpg` is original artwork generated by `make_background.py` (the
original theme's default image is not redistributed). Put your own picture in
its place to get the original theme's "your picture, frosted" effect.
