# Frutiger Aero (test theme)

Glossy "Aero" look: a sky-blue to aqua backdrop, translucent glass panels
with white highlight lines, teal/green accents, bubbly rounded corners and
soft bubbles behind the chat.

`bubbles.png` is generated procedurally by `make_bubbles.py` (Python
standard library only); no outside images are used.

For testing RustCord's theme system only — not shipped with RustCord.

Install: Settings → Themes → *Import folder…* and pick this folder (or zip
it and use *Import theme…*).
