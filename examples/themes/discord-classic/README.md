# Discord Classic

The classic flat Discord look: Discord Dark with flat panes that touch
each other (no borders, gaps or pane labels), Discord's rounded corners,
round avatars and badges, and the Noto Sans font instead of the monospace
one.

Since 0.8.0 this look is built in as **Discord Dark** (Settings → Themes →
*Apply*), so you don't need to import it. The file stays as an example to
copy and change.

Install anyway: Settings → Themes → *Import folder…* and pick this folder
(or *Import theme…* and pick `theme.rctheme`), then *Apply*. Settings →
Themes → *Reset to default* goes back to RustCord Dark.
