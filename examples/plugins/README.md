# Example plugins

Not installed automatically. To try one, zip its folder (or pick the folder
itself) in Settings → Plugins → Install, then approve its permissions.

- `hello/` — `/shrug` and `/time` commands.
- `word-filter/` — hides chosen words in messages you see; settings section.
- `channel-notes/` — a panel with notes per channel.

The plugin API is documented in `docs/PLUGINS.md`.
